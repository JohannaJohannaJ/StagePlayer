# StagePlayer

Simple Android stage player for local audio + text and playlists.

## Build on GitHub
1. Create a GitHub repository and upload this entire project.
2. Open **Actions** → **Build StagePlayer APK** → **Run workflow**.
3. When the workflow finishes, open the run and download the artifact **StagePlayer-debug-apk**.
4. Unzip the artifact and install `app-debug.apk` on Android.

The APK is a debug build intended for personal use/testing. No Android Studio is required.
